## 观察与待办

1. **头部覆盖良好**:出现率 ≥0.1% 的类型中,仅 4 个三无(规则表✗码位✗相似组✗):
   **竖折提**(0.61%,元/允/尤的乚——楷体乚的弧被分类为折提)、**捺提**(0.49%,儿/也/匕的乚变体)、
   **竖捺**(0.40%,女/巛的撇点变体)、**捺折**(0.34%)、**横捺/横捺撇/横捺钩**(合计 ~0.4%,横折弯系变体)。
   这些是同一书法形态的"分类器方言",与标准类型的对应关系:
   竖折提/捺提 → 竖弯钩系;竖捺 → 撇点/竖捺系;横捺钩 → 横折弯钩;横捺撇 → 横撇(弯钩)系;横捺 → 横折弯。
2. **两条改进路线**(二选一或结合):
   a. 分类器归并——把上述方言在 `classifyMedian`/`_ALIAS` 层折算成标准名(影响面大,需全量回归);
   b. 相似组扩充——把方言名加进对应 `SIMILAR_GROUPS`(低风险,模板借用即可生效)。
3. **撇钩**(0.17%,反/氏/乐的首笔)有码位 U+31E2 但无规则表条目、无相似组——字体缺码位时无模板可用,
   建议入相似组(撇钩/撇/竖钩?)或补代表字。
4. 尾部 <10 次的复合名多为繁体复杂字的连笔段(灣25=灣的第25笔),不值得单独建模板,骨架宽容兜底即可。
