## 模块一:汉字拆解(strokelab.pipeline 包化)

pipeline.py(2862行单文件,runPipeline 巨函数+闭包)→ 按流程切包:

```
strokelab/pipeline/
  __init__.py    # runPipeline 编排器;兼容旧入口(import strokelab.pipeline as pl;
                 # pl.LADDER_PROBE=True 这类模块属性开关必须继续可用)
  state.py       # PipelineCtx dataclass:各阶段共享状态的显式协议
                 # (contours/组表/medians/initMedians/widths/costRows/
                 #  strokeGroup/groupStrokes/kai/affine/penMatrix/诊断/timings)
  helpers.py     # 模块级纯函数:_hungarian/_switchbackCount/_axisFails/
                 # _reMedianFromStroke/_selfSeeds/_secondPassBetter/...
  grouping.py    # 轮廓解析+交叠并组+组表
  dbuild.py      # 全局对齐 + D构建(模板选择/放置/吸直)
  assign.py      # G0代价/penMatrix/G1匈牙利/S1b语义认领
  arbitrate.py   # G2..G8 + G8.5梯队(探针+执行器)
  anchor.py      # G9组重锚定/G10断面吸附
  iterate.py     # contourAllowed冻结+采样归属迭代+refine/recenter+终态吸直
  cutting.py     # 主人判定/边弧归属/标签平滑/矢量切割/划分重构
  finalize.py    # 布尔收口/终态中轴重提/shapeSim/result组装/自洽二遍/轴向守卫
```

纪律:一次抽一个阶段→跑 parity(34例0差异)→再抽下一个;闭包变量改经
PipelineCtx 显式传递;阶段函数签名 stage(ctx) -> None|局部产物;任何
parity 失败先回退该步。楷体/字体库侧(datahub/fonthub/classify/geometry/
boolean/verify/bench)本轮不动(已是清晰模块)。

## 模块二:矢量动画(viewer JS 模块化)

charStrokeLab.html(2081行,内嵌全部JS)→ 拆静态 js(server 已能服务
/viewer/* 静态文件):

```
viewer/js/
  core.js      # api/fetchDeco缓存/el/glyphGroup/colorOf/state(拆解协议消费端)
  fxUtils.js   # 统一单元操作:采样(含子路径级)/对齐/插值/缓动/fitBox/
               # 声调/部件变体表——所有效果只许经此复用,禁止私有副本
  fxSingle.js  # ⑦单字效果(每效果一个 async fn(ctx))
  fxMulti.js   # ⑧多字效果(同上)
```

效果单元统一签名:`async effect(ctx)`,ctx={svg,root,chars,decos,setInfo,
anim,token}——新效果=新函数+一行注册,与既有零耦合。

## 新特效(随重构一并落)

1. 子路径精细配对:带孔笔画(口形)按 M 切子路径,各子路径独立成环、
   按面积序+质心邻近配对插值;无配对的子路径向自身质心塌缩/由质心生长。
   替换 swapMorph/family/morphStruct 的整串环近似,消除连接伪影。
2. 任意字变形:任意两字整字插值(全笔画双向并集比例配对+子路径级
   插值,B 整字盒 fitBox 进 A 盒),不要求任何结构/部件关系。
