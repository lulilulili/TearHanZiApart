# 任意字输入 → 拆解结果:全流程审查图(2026-09-26,对照 c7689f8 实码)

> 用途:用户审查。图中 ◆=判定点(括号内为阈值/开关),⚠=已知薄弱点。
> 阶段名与代码模块一一对应(strokelab/pipeline/ 包)。

## 0. 总览:一次请求的完整旅程

```mermaid
flowchart TB
    IN["用户输入字 X + 字体 F"] --> SRV["服务层 /api/decompose<br/>◆key级Future去重(同字并发只算一次)<br/>◆bytes LRU缓存(命中直接返回)"]
    SRV -->|缓存未命中| LIB["阶段一 库准备(每字体一次,磁盘缓存)"]
    LIB --> KAI["阶段二 楷体参照准备 DataHub.kai(X)"]
    KAI --> PIPE["阶段三 拆解管线 runPipeline"]
    PIPE --> R2{"◆自洽二遍?<br/>(非满分才触发)"}
    R2 -->|种子重跑| PIPE2["管线重跑(前段复用FrontReuse)"]
    PIPE2 --> ADOPT{"◆双指标采纳门"}
    ADOPT -->|更优| OUT
    ADOPT -->|否| R3
    R2 -->|满分跳过| R3{"◆轴向守卫?<br/>(横竖主轴偏>32°)"}
    R3 -->|病笔楷体种子重跑| PIPE3["管线重跑(复用同上)"]
    PIPE3 --> ADOPT2{"◆四指标不倒退门"}
    ADOPT2 --> OUT["result JSON<br/>strokes/median/组/槽位/holes/trace/kai透传"]
    R3 -->|无病笔| OUT
```

⚠ 重试层:重试遍是整管线复跑(重试字耗时约 2×),采纳门只看聚合指标,
单笔变差聚合仍升会被采纳(蝮 曾被二遍顶出 OVERLAP,靠 veto 补丁挡)。

## 1. 阶段一:库准备(每字体一次,.blibCache 按 字体签名×算法签名 缓存)

```mermaid
flowchart TB
    F["字体文件"] --> B0["逐楷体类型建 B 库(70类)"]
    B0 --> C1{"◆U+31C0-31E5 笔画码位有字形?"}
    C1 -->|有| TAKE["直接取码位字形(短路)"]
    C1 -->|无| C2{"◆规则表 KAI_TARGET_MAP<br/>(代表字+位置词→孤立提取)"}
    C2 -->|命中| EXT["从代表字连通组提取<br/>◆纯度投票(显式探针60%/其余95%)"]
    C2 -->|缺| BOOT["自举:拆简单字回灌"]
    TAKE --> SK["骨架提取 outlineCenterline<br/>Voronoi中轴直径路径<br/>◆端枝剪除(0.9×中位余隙,上限2.4×+8)"]
    EXT --> SK
    BOOT --> SK
    SK --> POST["midpointRectify + straightenSections<br/>(直段吸直/拐角保留/真曲保持)"]
    POST --> SAVE["落盘 .blibCache(原子写)"]
```

⚠ 码位短路信任码位字形与楷体同型——捺曾因码位笔误(0x31D2撇)整族取到
镜像形,宋体首当其冲(已修,但同类映射错误无自动校验)。
⚠ 骨架是折线(采样±平滑),无曲线拟合——中线"歪扭"的源头之一。

## 3. 阶段三:管线主干(模块=实际文件)

```mermaid
flowchart TB
    A["grouping.parseAndMerge<br/>轮廓解析+绕向判孔+交叠并组<br/>◆并组门:组数>楷体笔数 且 相交面积>25"]
    A --> B["dbuild.run 全局仿射对齐(楷bbox→字形bbox)<br/>+逐笔D构建:B库同类型候选扫描<br/>◆相似组借用(本型优先,借用须优0.08)<br/>◆形态偏差门(0.18/0.28)|缺型退楷体中轴"]
    B --> C["grouping.buildTables 组表"]
    C --> D2["assign: G0墨距离costRows+penMatrix罚<br/>(杆⊥200/点锚250/barcap200默认开)<br/>→G1匈牙利全局锚定→S1b空组语义认领"]
    D2 --> E["仲裁链 G2..G8.5F(见下图)"]
    E --> F2["anchor: G9组重锚定(◆联合框覆盖<0.8,<br/>ladderTouched豁免)→G10断面吸附<br/>⚠G10阈值35%绝对值,simsun 95%触发/33%采纳"]
    F2 --> G2["iterate: contourAllowed冻结→<br/>采样归属迭代×5轮(批量打分d/halfW+0.5·dirPen)<br/>每轮refineMedianFit拉拽+recenterMedian断面居中<br/>◆居中位移上限0.6×笔宽|◆饿死<6样本退楷体中轴"]
    G2 --> H["cutting: 主人判定→边弧整体归属→标签平滑→<br/>De Casteljau精确切割→环路追踪+直割线弦桥+跨轮廓并环"]
    H --> I["finalize.sealUnion 收口链(见下图)"]
    I --> J["终态中轴重提(◆仅折返>75°才触发)+shapeSim"]
    J --> K["buildResult 组装"]
```

⚠ dbuild 的 D 位置质量决定归属起点;衬线体楔形笔的骨架/断面天然带弯。
⚠ iterate 的中线是打分脚手架,精调拉扯痕迹会留到终态(重提仅折返触发)。
⚠ cutting 的边界由采样投票局部决定,模板形态先验不参与边界走向——
交界毛边/入侵的结构性来源(形态修复器半成品在工作区,默认关)。

## 4. 仲裁链(arbitrate,按执行序;全部记 trace)

```mermaid
flowchart TB
    G2["G2 corridorFit 走廊可容纳度<br/>◆代价≥15/窗口max(35,0.6×)/支撑≥1.3×"]
    G2 --> G3["G3 componentMate 部件亲缘<br/>◆matches前缀相容+代价窗"]
    G3 --> G4["G4 barOverload 单杆超载+垂直蹲杆<br/>◆_isBar(无孔+elong≥4)/弦>2×杆厚"]
    G4 --> G5["G5 barTheftSwap 抢杆认领链<br/>◆笔长>1.08×杆长 ⚠触发40%采纳3%(空转)"]
    G5 --> G6["G6 axisMisplace 轴向错家全排列<br/>◆偏差>50°名单/总降30°"]
    G6 --> G7["G7 slotSwap 槽位互换<br/>◆互错×1.8/代价≤+60"]
    G7 --> G8["G8 orderPreserve 楷序互换<br/>◆间距≥180反向>60/代价≤+30<br/>⚠误换病例:目族5字(豁免判据未做)"]
    G8 --> L1["G8.5 梯队探测(A/B错位链·C跨位·D单争议)<br/>◆零误触标定过的多重门"]
    L1 --> L2["G8.5 执行(组重排+中轴锚条带y)<br/>◆重置后代价≤40/空组断言/整包回滚"]
    L2 --> LF["G8.5-F 融合框(◆dangle落墨率<0.5预筛→<br/>组级交叉行锚定→◆9点落墨率≥0.7)"]
```

⚠ 整链是"先错分再逐级修"的两段式;胜率表已量化各级效率,矩阵归并
(把 unary 证据折进锚定)只走完第一拍(barcap),G2 走廊未归并。

## 5. 收口链(finalize.sealUnion)+已知病区

```mermaid
flowchart TB
    S1["rescueStarved 饿死救济<br/>(骨架走廊∩组区域重建)"]
    S1 --> S2["clampStrokes 裁剪+残差回填<br/>(不多:∩原形;不少:未覆盖片给邻笔)"]
    S2 --> S3["resolveKaiDisjointOverlaps<br/>楷体不相交笔对重叠减除(亨/亭封底横)"]
    S3 --> S4["enforceConnectivity 单笔单连通"]
    S4 --> S5["reUnionCheck 真实路径口径终检"]
    S5 --> S6{"◆cover<99.95?"}
    S6 -->|是| S7["fillResidualGaps 补缝"]
    S6 --> S8{"◆excess>0.5 或 cover<99.5?"}
    S7 --> S8
    S8 -->|超标| S9["再收口一轮(硬保证优先)"]
    S8 --> S10["MORPH_REPAIR 毛刺置换<br/>⚠半成品,默认关,门禁未走完"]
    S9 --> S10
```

⚠ 收口链保证并集恒等(不多不少),但**不保证形态**——桥接三角/毛边/
被啃的臂都能通过恒等校验(simkai草小三角/simsun永横折钩实例)。

## 6. 审查提示:各环节的"决定权"分布

| 问题类型 | 决定环节 | 现状 |
|---|---|---|
| 笔画归属对不对 | assign+仲裁链+iterate | 主门97.39%,交叉区/融合框是残余大户 |
| 边界切在哪 | iterate采样投票+cutting | ⚠无形态先验参与,毛边源头 |
| 中线好不好看 | dbuild骨架+iterate拉扯+终态重提 | ⚠折线表示+条件触发重提,未拟合 |
| 形态像不像标准笔画 | (无环节负责) | ⚠仅事后审计(morphBad软指标),修复器未收官 |
| 部件/槽位识别 | 楷体参照锚定(matches) | 数据缺口已量化(见阶段二) |
