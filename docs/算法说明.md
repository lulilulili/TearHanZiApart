# strokelab 拆字算法说明

> 与代码同步维护。本文按 `runPipeline` 实际执行顺序描述当前方法;历史演进与逐版修复记录见《方案评估与说明.md》。

## 零、设计原则与硬保证

1. **纯矢量**:全程无像素/SDF 判定,输出是原字形贝塞尔段的精确切片;
2. **并集恒等**(硬保证):所有笔画并起来与原字形不多不少,由布尔收口兜底;交叠区允许**双重归属**;
3. **楷体只供结构、不供形态**:笔顺/类型/大致位置来自 MakeMeAHanzi 楷体(结构 C),笔画长相来自目标字体自己(B库);
4. "整字拼得回"≠"每笔拆得对",后者靠保留率(retain)/形状匹配(shapeSim)/难例基准另行把关。

## 一、建库(每字体一次,全自动,带磁盘缓存)

- **A库** = 文鼎楷体标准笔画;
- **B库** = 目标字体标准笔画,三个来源按优先级:
  1. 字体自带 U+31C0–31E5 笔画区;
  2. 规则表(32类 × 独立/少相交代表字)从孤立连通组拆取,尺度不变形状描述子校验;
  3. **自举回灌**(`completeLibraryB`)——对仍缺的类型用当前管线拆代表字,过质量闸(保留率≥90% 直接放行;否则保留率≥55% 且形状≥40%)入库;
- **A↔B 映射**(`ensureSkeleton`):楷体同类型中轴线 bbox 映射进 B 笔画轮廓并单笔精调,得到目标字体自己的笔画形态骨架;
- **磁盘缓存**(`.blibCache/<字体>.json`):键 = 字体文件(大小+mtime)× 算法签名(核心源码内容哈希,算法一变自动失效);建库(base)与自举补全(full)分两阶段存取,保证有无缓存行为一致。实测快乐体全库 33s → 0.04s。

## 二、单字拆解管线(runPipeline)

### ① 轮廓解析与标注
M/L/Q/C 解析为三次贝塞尔段;**绕向法判孔**(与最大轮廓绕向相反=孔;奇偶嵌套法会误杀"孔中悬浮实体",如亘);每个外环+挂靠其上的孔 = 一个**连通组**。

### ② 全局对齐
楷体整字包围盒 → 目标字形包围盒的仿射变换 `affine`。

### ③ D 构建(相似组候选 + 模板-结构一致性检查)
每笔模板候选按序尝试:**本类型 → 相似笔画组内类型(借用)**,每个候选都过一致性检查,全部不合格才退回楷体中轴线。

- **相似笔画组**(classify.SIMILAR_GROUPS,用户规则):不同字体设计有微妙差别,同一笔可能在类型边界摇摆(一个字体的横折钩在另一个字体形如横折)。分组:提↔横;横折/横折钩/横撇/横钩;横折折/横折提;横折折撇/横折折折;竖/竖撇;撇/提;点/捺;竖提/斜钩/竖弯;竖/竖钩/弯钩;竖折折/竖折弯钩;扁斜钩/竖弯钩;横斜钩/横斜弯钩。
- **一致性检查**:候选骨架放进"楷体该笔包围盒仿射框"后,与楷体中轴线按弧长重采样 24 点对齐比较,平均偏差 > 0.28×对角线即判**形态错配**淘汰——同名类型分段比例可能迥异(宀的横钩钩段占 13%,横撇模板撇段占 60%,压进矮扁包围盒后长尾侵入邻笔)。

### ④ 连通组分治(v8,全局最优指派)
公理:正常字体设计中,同一笔画不会断成两个孤立连通组。每笔对各组算**墨距离**(中轴线采样点在组墨内=0,否则到组边界最近距离,取均值);**匈牙利算法全局指派**——每组先配一个"锚定笔"(保证无空组;逐笔独立 argmin 曾让㡭的点挤进邻组、正主组空置),余下笔画就近入组;组数=笔画数时退化为严格一一对应。此后**归属评分只允许本组的笔竞争本组的轮廓**;一组恰一笔=整组直出(保留率100%、零切割)。

### ⑤ 迭代归属+精调(×5 轮)
轮廓按弧长采样(带切向);评分 = 到延长中轴线的距离/半笔宽 + 0.5×方向不一致罚;逐样本取组内最优标签。每轮:
- 笔宽 = 己方样本距离中位数×2,夹在全字中位宽的 0.55–1.6 倍;
- **饿死自救**:某笔 <6 样本 → B 骨架判劣质,D 退回楷体中轴线重新参赛;
- `refineMedianFit` 精调:直笔=平移+主轴伸缩(0.7–1.8×);折笔=按拐角分段平移+两段折沿轴伸缩(0.85–1.35×/轮,锚定拐角向自由端生长);位移钳各向异性(横向严 ≤max(80,1.3w)、沿轴宽 ≤0.45×笔长);
- 总长硬约束(0.6–1.4×,防小笔画复利拉爆);
- **断面居中**(`recenterMedian`):沿法向找字形边界双侧交点,移到所在实体断面中点(拐角点、断面过宽处不动),治"只按己方样本拟合"的贴边漂移。

### ⑥ 主人判定整体归属
孤立/叠压的完整笔画轮廓整体判给主人。主人资格 =(初始+精调占比 ≥0.55/≥0.35)或(精调占比 ≥0.8 且已握 ≥60% 样本——初始落位失败但精调收敛,如天的撇);**竞争者** = 占住轮廓且实际握 ≥20% 样本的他笔(存在则不接管;中轴线只是路过的不算);**饿死保护** = 接管令某笔别处剩 <6 样本(绝对)或夺走其过半样本(相对)则跳过。

### ⑦ 边弧整体归属
按角点(相邻段切向夹角 >40°)把轮廓切成边弧。**直弧**(弧内累计转角 ≤40°)必然单主,整弧按平均分归属;弯长弧(>3×中位笔宽)且分歧成块(主导 <75%)保留逐样本(保护连笔字体的真实过渡)。**孔洞边弧**:从弧上探"断面中心"(通道中点)打分——兼顾环形内缘(口)与藏于孔洞间的内笔(日的中横);探不到通道退回径向对应多数票。顺序:先外轮廓收敛 → 孔洞径向对应(只认本组外缘)→ 孔洞整弧。附饿死保护(基数只数非孔样本)。

### ⑧ 标签平滑
≤2 个样本或 <15 长的碎 run 并入邻段,最多 3 轮。

### ⑨ 矢量切割
标签跳变处定切点:两样本间恰有角点则**吸附角点**,否则沿轮廓参数二分 22 次;De Casteljau 精确切片,原曲线几何不变。

### ⑩ 划分式重构
全轮廓单标签→整环直出;开弧按"同轮廓按序串联 → 跨链近端串联(上限 max(2.5×笔宽,160)) → 回绕闭合"组环。缺口用**笔锋桥**:两端切线延长交于 CP、两中点为控制点的三次贝塞尔(借鉴大力智能/MMH);切线近平行/交点反向/CP >1.2×弦长退回直割线。**碎片环剪除**:保留弧长 < max(60, 45%×主环) 的 junk 环丢弃,面积由收口回填归还。

### ⑪ 收尾:救济 → 收口 → 连通 → 校验
1. `rescueStarved`:颗粒无收/零宽退化的笔,用楷体骨架走廊(组局部仿射)∩本组区域补一个实体;
2. `clampStrokes`:每笔∩原形(保证"不多");与原形交集为空的整笔置 failed(退化重构环的奇偶区域可能整体翻到界外)→ **重走一次救济再收口**;未覆盖残差按共享边界回填(保证"不少");
3. `enforceConnectivity`:单笔单连通终态收口(多片留最大,面积≥25 的余片一律划给接壤最长的邻笔——曾用"≥2%笔面积"相对阈值,放过了肉眼可见的残片);
4. **终态校验统一用 `reUnionCheck`(按实际路径口径)**——clampStrokes 的返回值基于裁剪区域,会掩盖未替换路径的残余溢出;
5. shapeSim:D′ vs 楷体同笔,尺度不变形状匹配。

### ⑫ 自洽回灌(第二遍)
第一遍拆完,逐笔用**自己拆到的几何**重提干净中轴(轻平滑保拐角+对本笔断面居中×2)作种子重跑一遍。采纳门槛四重把关:
1. 并集守卫:覆盖/溢出不得比第一遍恶化(流江水的二遍曾溢出 14.2%);
2. 失败笔数不增;
3. retain 均值 +0.005 以上且 sim 均值不降超 1(防吞并式虚高);
4. 位置守卫:逐笔质心相对楷体映射位置的偏差恶化 ≤0.04×对角线(sim 尺度不变、看不见"整笔挪去别人地盘")。

### 耗时打点与性能
`result["timings"]` 逐阶段毫秒;服务端 `serverTimings` 含库准备/拆解;页面顶栏实时显示。已落实的优化:B库磁盘缓存(33s→0.04s);glyphRegion 全收口链路只算一次;组分治墨距离矩阵包围盒下界预筛+粗边界折线(3-8×);自洽二遍两道零行为差异闸(满分字必然无收益跳过、种子与精调中轴几乎重合跳过)。

## 三、质量体系

- **verify**(`strokelab/verify.py`):8 类不变量、多进程全字符集(鸿蒙SC 9570 字,当前通过率见 verifyOut/);
- **bench**(`strokelab/bench.py`):65 个难例 golden 快照(包围/交叉/同类笔画/小笔画 × 5 字体),逐笔面积 IoU <0.85 报警;golden 带 verified/known_bad/unverified 三态,目检页 bench/review.html;
- 17 字 × 13 字体回归快照(retain/sim/cov/ovf 逐项 diff)。

## 四、结构诊断与路线

真正的机制 6 个:建库映射、组分治、评分迭代、切割、重构、收口;其余均为护栏(各对应一个实际踩过的坑,见《方案评估与说明.md》逐版记录)。

已知框架性弱点:**归属由四层机制接力覆盖**(逐样本评分→主人判定→边弧归属→平滑),每层需自带饿死保护/例外通道——这是贪心逐边打分框架的天花板(好的横被吞、黑体中的横折即其边界样本)。下一阶段"**候选连接+整字结构约束的联合选择**":切口候选来自角点对,归属候选按组枚举,整字级证据(位置/笔宽连续性/形状)一次选择最优解释,可合并中间三层并退役约半数护栏。备选工具:MMH 拐角配对 8 维几何特征及其公开权重;CCSSD 数据集可做大规模栅格化 MIoU 评测。
