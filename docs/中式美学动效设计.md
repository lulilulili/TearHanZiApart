# 中式美学动效设计方案(v1 类别清单,待用户视觉裁定后落地)

> 定位:把"机械位移"升级为"书法动力学 + 汉字构法哲学"。本文档只做
> 方案分类与可行性裁定,**不含实现**;每类列出:效果构成、依赖的数据
> /技术件、现有资产覆盖度、需要用户设计的规格。

## 我们的独有资产(方案的地基)

其他方案(像素分割/视觉大模型)给不出这些,这是"气韵"能落地的前提:

| 资产 | 美学映射 |
|---|---|
| 每笔 median 中轴线(带笔序) | **笔势**:起笔→行笔→收笔的时间轴;粒子/墨的运动轨道 |
| 每笔闭合轮廓 + 笔宽 | 顿挫粗细;牵丝的附着点(断裂处=相邻笔 median 端点对) |
| 楷体笔序 + 部件归属(matches) | **笔断意连**:拆解顺序=书写逆序,重组=笔顺;部件级避让穿插 |
| 空腔 holes(并集内环) | **计白当黑**:留白区域是已知几何,可注入晕染/云雾 |
| etymology 义旁/声旁 + hint | **六书语义**:象形/会意/形声驱动的分层效果 |
| radicals.json registry(建设中) | 偏旁→自然元素绑定表(氵→水,灬→火…)的数据源 |
| 中轴图交叉点(medialJunctions) | 部件"筋骨"关节点:牵引/呼应的锚点 |

## 类别一:笔势牵引·笔断意连(书法动力学) — 可行性:高,纯前端

**效果构成**
1. **牵丝(游丝)**:拆解时相邻笔的 median 端点间拉出贝塞尔细线,
   随距离拉长变细,超阈值断裂(端点微弹);重组时后笔沿前笔收笔切向
   入场(笔势顺承)。
2. **顿笔震动**:部件落位瞬间按笔宽做 1-2 帧过冲+回弹(easeOutBack
   已有),落位次序=楷体笔顺。
3. **飞白拖尾**:快速移动的笔画沿 median 反向留半透明干笔拖影。

**依赖**:median 端点/切向(有)、笔序(有)、缓动库(有)。零新后端。
**需用户设计**:牵丝的粗细/颜色/断裂阈值;顿笔幅度;是否全局默认开启。

## 类别二:六书语义拆解(拆法即字理) — 可行性:高,依赖 registry

**效果构成**
1. **会意字剧场**:明=日月交替(色温金→银过渡)、森=三木随风错相摇曳
   (matches 路径已能分别寻址三个木)、休=人倚木斜靠。
2. **形声字义音双声部**:义旁走自然元素动效(类别三),声旁走"音"的
   表达(脉冲/声波环)——义音分层已有骨架,升级表现力。
3. **象形字回源**:雨字四点做下落轨迹重放、风字撇捺做气流弹性——
   227 个 pictographic 字按 hint 配小剧本。

**依赖**:etymology(有)、registry 语义标签(agent 在建)、
每字小剧本表(**新数据件**:charScripts.json,语义→动效脚本映射)。
**需用户设计**:首批 20-50 个字的剧本清单(哪个字、什么意象、什么节奏);
色温/配色规范。

## 类别三:自然意象粒子(偏旁→元素) — 可行性:中高,需粒子层

**效果构成**
1. **氵/雨族**:笔画粒子化为雨滴沿重力落下,落到屏幕沿/其他笔画上
   凝聚回流成字(霖/江/清);
2. **灬/火族**:笔画边缘升起火星粒子,拆解=灰烬飘散,重组=火苗聚拢;
3. **艹/木族**:生长动画(笔画沿 median 从根部"长"出来,已有书写动画
   可复用为生长)+微风摆动(顶端小幅正弦摇曳);
4. **风/气流**:用户滑动轨迹产生涡流场,笔画粒子入涡盘旋后借势收拢。

**依赖**:median 轨道粒子(义音分层已有雏形)、轻量粒子系统(**新前端
件**:fxParticles.js,建议 canvas 叠加层而非 SVG,千级粒子 60fps)、
registry 的 particle 字段(agent 在建)。涡流可用简化 curl-noise,不必
真流体。
**需用户设计**:每类元素的粒子形态图(雨滴/火星/叶片的矢量小图元)、
密度/寿命/重力参数感、触发方式(自动 or 交互)。

## 类别四:计白当黑·留白活化 — 可行性:中,几何已就绪

**效果构成**
1. **墨晕负空间**:拆解时 holes 空腔与部件间隙浮出水墨晕染(径向
   渐变+噪声蒙版),部件离场晕染扩散、归位收敛;
2. **隐/现**:静态时字淡化为背景暗纹,指尖光影划过处如水中倒影般
   聚焦清晰(SVG mask+径向渐变跟随指针);
3. **深度留白**:汇聚景深已有三档模糊,升级为"留白也有远近"——
   背景晕染与前景笔画反向景深。

**依赖**:holes(有)、组间隙几何(可由组 bbox 差集近似)、噪声纹理
(前端生成或贴图)。
**需用户设计**:墨的质感基调(生宣晕散 vs 熟宣锐利)、隐现的触发
交互(指针/时间/语义)。

## 类别五:金石材质(阴阳刻/玉石) — 可行性:中低,建议后排

浮雕/玉石质感在 SVG 里只能用滤镜近似(feSpecularLighting 浮雕感+
重力光影随设备倾斜),真材质需 WebGL(three.js 挤出笔画路径为 3D)。
**裁定建议**:先用 SVG 滤镜做"拓印/印章"轻量版(阴刻=挖空+内阴影,
朱文白文切换),WebGL 版列入远期;声效(玉石轻碰)是纯资产问题。
**需用户设计**:材质参考图、是否引入 three.js 的决断。

## 类别六:情境语义动效(崩/融/隐/风) — 可行性:高,依赖剧本表

"崩"山旁滑坡(重力+碎裂=倒塌效果的语义定向版)、"雪/冰"融滴
(笔画下缘生成水滴+路径消融)、definition 关键词→场景包自动匹配。
与类别二共用 charScripts.json 剧本表;倒塌/爆炸物理已有。
**需用户设计**:语义→效果映射表首批条目;负面语义(崩)的使用边界。

## 落地顺序建议(裁定后执行)

1. **类别一(笔势牵引)**:零新依赖,给现有全部效果统一加"书法手感",
   性价比最高;
2. **类别三①雨+③生长**:registry particle 字段就绪即可做,fxParticles.js
   一次建成三类复用;
3. **类别四②隐现 + 类别二①明/森剧场**:演示叙事性;
4. 类别五印章轻量版、类别六剧本表批量扩展。
