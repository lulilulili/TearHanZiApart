1. **recenterMedian 位移硬上限**（geometry）：断面居中修正超 0.6×笔宽
   一律拒绝——交叉区断面中点在两笔间跳，是中轴线蛇形折返的根源。
2. **终态中轴线重提**（pipeline，收口后）：median 残留折返时，用切割
   定稿的单笔多边形走 B 骨架同款 Voronoi 直径路径 + midpointRectify +
   吸直重提。切割后"笔画本身的中轴线"才是良定义的。不回改切割。
3. **轴向守卫重试**（pipeline，自洽回灌后）：名义横/竖切出主轴偏差
   >32°（verify TYPE 同款判据）⇒ 病笔换楷体中轴作种子、健康笔保留
   精调结果重跑一遍；采纳须病笔数下降且失败笔/retain/sim/并集全不倒退。

## 剩余失败类型的修复方向（按优先级）

1. **TYPE 残余 ~350 字**：轴向守卫只救"D 歪了"的病例；剩余是
   楷体笔型与字体真实笔型不一致（TC 尤多）+ 复杂交叉区归属错误。
   方向：①病笔连同其杆组/走廊邻笔一起重仲裁（现在只换病笔种子）；
   ②终极方案是搁置中的"候选连接+整字结构约束联合选择"。
2. **ORDER（164+新增）**：质心方位判据对细长笔敏感。方向：仲裁阶段
   加入笔序先验（楷体质心相对方位做软约束进指派代价矩阵）。
3. **AREA 残余**：检出的 (缩,涨) 笔对之间做定向面积回迁（rescueStarved
   已有局部走廊重建，可按对定向触发）。
4. **OVERLAP（手写体大头）**：连笔字形两笔共享墨块，当前硬切必重叠。
   方向：交叠区按中轴线距离场做软划分——或承认连笔场景改评价口径
   （允许重叠但并集恒等仍硬保）。
5. **SPLIT 残余**：切碎后走廊回收（把打断连通的他笔小块按共享边界
   还给被切碎笔）——enforceConnectivity 已有骨架，需加"夺回"方向。
